Side Quests & Fun Projects

📅 Interactive Sandbox ⏱️ Creative coding 🏷️ Side Experiments

Beyond building production-ready APIs and blockchain engines, I enjoy creative coding and building interactive side quests. Here is a showcase of fun scripts, mini-games, and UI experiments.

Current Side Quests

  • Interactive Pointer FX: An interactive canvas physics system that connects cursor movements to digital neurons, rendering dynamic synapse lines (similar to the scrollytelling background of this portfolio).
  • Web-Audio Synthesizers: Simple scripts utilizing the Web Audio API to create synthesized sound feedback for UI triggers and buttons, creating an immersive acoustic experience.
  • Simulated MetaMask Runtimes: Mocking blockchain signatures and gas parameters completely inside a client-side sandbox to demonstrate DApp integrations without requiring real mainnet gas fees.

Why Build Side Quests?

Experimenting with creative code is how I push limits, learn new APIs, and find unique design integrations that eventually make their way into production applications. Stay tuned for new releases!
